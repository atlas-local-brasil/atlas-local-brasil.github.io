# Atlas Local Brasil — GitHub Pages

Pacote estático preparado para publicar como **site de usuário/organização do GitHub Pages**.

## Domínio previsto

`https://atlas-local-brasil.github.io/`

Para esse endereço funcionar exatamente assim, o proprietário (usuário ou organização) no GitHub deve se chamar `atlas-local-brasil` e o repositório público deve se chamar `atlas-local-brasil.github.io`.

## Publicação

1. Crie ou use o usuário/organização `atlas-local-brasil`.
2. Crie o repositório público `atlas-local-brasil.github.io`.
3. Envie **todo o conteúdo desta pasta para a raiz do repositório**.
4. Abra **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Branch: `main`; pasta: `/(root)`; clique em **Save**.
7. Aguarde o deployment ficar verde em **Actions** / **Pages**.

## Verificação no Ahrefs

Quando o Ahrefs fornecer um arquivo de verificação, coloque esse arquivo **na raiz do repositório**, ao lado de `index.html`, `robots.txt` e `sitemap.xml`, faça commit e aguarde o GitHub Pages publicar. Depois abra a URL exata indicada pelo Ahrefs e só então clique em Verificar.

## Observação sobre o domínio

Se `atlas-local-brasil` não estiver disponível como usuário/organização, **não publique este pacote com outro endereço sem atualizar canonical, Open Graph, Schema, robots e sitemap**. Informe o endereço final para gerar a versão correta.
